## ⚔️ Visão Geral — Raridade e Aquisição

| Raridade | Descrição | Como Conseguir |
|----------|-----------|----------------|
| **Comum** | Itens mágicos menores (poções, pergaminhos, componentes) | Lojas, alquimistas, mercado |
| **Incomum** | Armas/armaduras +1, itens com efeito menor | Guilda ERA, artesãos mestres, recompensas |
| **Raro** | Itens com poderes significativos, história | Missões perigosas, ruínas, inimigos poderosos |
| **Lendário** | Único, história épica, muda o jogo | Fim de campanhas, vilões maiores, patronos divinos |
| **Artefato** | Poder que altera o mundo; único em Airy | Fim de era, deuses, cataclismas |

## 🏷️ Propriedades Comuns (3D&T)

| Propriedade | Efeito Mecânico (3D&T) |
|-------------|------------------------|
| **Acerto Crítico Automático** | 1×/combate: ataque vira crítico (FA = F + PdF) |
| **Anula Crítico** | 1×/combate: crítico recebido vira dano normal |
| **Armadura Extra: Magia** | Gasta PM → Armadura = A por turnos = A |
| **Dano Dobrado (Escudo)** | Escudo causa dano = 2 × F (ignora H) |
| **Escudo Protetor** | 1×/dia: soma sua Armadura à de adjacente |
| **Regeneração** | Recupera PV/rodada; imune a Infestação (Auçá) |
| **Fraqueza Específica** | Obsidiana anula regeneração; Perda na presença |
