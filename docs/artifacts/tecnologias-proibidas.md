# Tecnologias Proibidas (Aparatos)

> **Equipamentos que o Império proíbe; pena de morte por posse, fabricação ou conhecimento.** Apenas Arcanos Imperiais, Senado e facções sombrias têm acesso.

---

## ⚙️ Necromechas

> *Máquinas de guerra colossais; exoesqueletos gigantes com interface neural; a tecnologia mais temida de Airy.*

### Necromecha Padrão (Produção)
| Especificação | Detalhe |
|---------------|---------|
| **Altura** | 12-15 metros |
| **PdF** | 10+ (escala gigante) |
| **Piloto** | 1 (interface neural; requer cirurgia) |
| **Custo Operação** | 1 PM/turno (piloto gasta PM para mover/atacar) |
| **Fonte de Energia** | Núcleo de Mana (recarrega em [jurubatiba](../factions/reinos/jurubatiba.md)/Ypy) |
| **Tripulação** | 1 piloto + 2-3 apoiadores (manutenção, recarga) |

### Armamento Padrão
| Arma | Alcance | Dano | Especial |
|------|---------|------|----------|
| **Canhão de Mana** | Longo | 4d6 + F (gigante) | Perfura PdF; gasta 2 PM/tiro |
| **Lâmina Rúnica (Braço)** | Perto | 3d6 + 2×F | Ignora PdF não-mágico |
| **Míssil Rúnico (Ombro)** | Longo | 5d6 | Teleguiado (OR); 1×/turno |
| **Escudo de Energia** | Pessoal | PdF +5 (gigante) | Gasta 1 PM/turno; bloqueia magia |

### Necromecha Protótipo (Único - Laboratório Secreto do Senado)
| Especificação | Detalhe |
|---------------|---------|
| **PdF** | 12+ |
| **IA Tática** | Autônomo; não precisa de piloto constante |
| **IA** | Toma decisões táticas; prioriza sobrevivência do "ativo" |
| **Autonomia** | 1 hora sem piloto; depois precisa de piloto ou desliga |
| **Armamento** | 2× Canhão de Mana + 4× Míssil Rúnico + 2× Lâmina Rúnica |
| **IA Tática** | Aprende com batalhas; adapta estratégia |
| **Localização** | Laboratório secreto (Senado); acesso: Imperador + Magistrado + Arqui-Mestre |

### Requisitos de Piloto
| Requisito | Detalhe |
|-----------|---------|
| **Cirurgia Neural** | Implante na base do crânio; irreversível; 30% mortalidade |
| **Atributos Mínimos** | F 4, H 3, A 2, R 3 |
| **Treinamento** | 2 anos (simulador + real); 50% desistem |
| **Custo Mental** | 1 PM/turno operando; exaustão mental real |
| **Risco** | Feedback neural → dano mental (PV/PM); loucura prolongada |

## ⚔️ Espadas de Poder (Rúnicas)

> *Armas de alta tecnologia arcana; canalizam mana; teleportam; só Arcanos elite.*

### Classificação por Nível

| Nível | Nome | FA | Efeitos Especiais | Quem Pode Usar |
|-------|------|----|-------------------|----------------|
| **Básica** | Espada de Poder | +2 | Canaliza PM → +1 FA/PM; ignora armadura não-mágica | Arcanos (Mestres+) |
| **Avançada** | Espada de Poder Avançada | +3 | +1 FA; 1 PM → ignora PdF; 1×/cena: *Teleporte Curto* (OR, 20m) | Gram-Mestres |
| **Suprema** | Espada de Poder Suprema | +4 | +2 FA; 1 PM → *Corte Dimensional* (abre fenda planar 1 turno) | Arqui-Mestre, Ahriman |

### Mecânica de Canalização
| Ação | Custo | Efeito |
|------|-------|--------|
| **Canalizar Mana** | 1 PM | +1 FA (1 turno) |
| **Ignorar Armadura** | 1 PM | Ataque ignora PdF não-mágico (1 ataque) |
| **Teleporte Curto (OR)** | 1 PM | Teleporte 20m (linha de visão) |
| **Corte Dimensional** | 2 PM | Abre fenda planar (1 turno); envia alvo para bolso dimensional |

### Fabricação
| Requisito | Detalhe |
|-----------|---------|
| **Runas** | OR (Espaço) + Fogo + [anti-fonemas](../magic/trevas.md) (estabilidade) |
| **Forja** | [jurubatiba](../factions/reinos/jurubatiba.md) (Capital Arcana) ou [kaluana](../factions/reinos/kaluana.md) (Oficina de Guerra) |
| **Mestre Ferreiro** | Mestre Ferreiro-Chefe (Kaluana) ou Mestre de Runas (Jurubatiba) |
| **Tempo** | 6 meses a 2 anos |
| **Custo** | 50.000 - 500.000 coroas (recursos + mão de obra) |

## 🏹 Cajado de Poder (Arcano)

> *Foco arcano supremo; canaliza mana ilimitada (gasta HP se PM acaba).*

| Nível | Efeito | Restrição |
|--------|--------|-----------|
| **Padrão** | +2 FA mágico; +2 PM/turno (regeneração) | Arcanos (Mestres+) |
| **Gram-Mestre** | +3 FA; +3 PM/turno; 1×/cena: *Cúpula de Energia* (grátis) | Gram-Mestres (7) |
| **Arqui-Mestre** | +4 FA; +4 PM/turno; 1×/dia: *Anti-Magia* (área 20m) | Arqui-Mestre (1) |
| **Supremo (Ahriman)** | +5 FA; mana ilimitada (gasta HP se PM=0); 1×/dia: *Morte Mágica* | Arqui-Mestre / Ahriman |

> **Mecânica**: Se PM = 0, gasta **1 HP por PM** necessário. Risco de morte real.

## 🔮 Orbe de Controle Mental

> *Artefato proibido; controla mentes; só Senado/Arcanos sombrios.*

| Especificação | Detalhe |
|---------------|---------|
| **Efeito** | Controla mente de alvo (teste H Difícil para resistir) |
| **Alcance** | Longo (linha de visão) |
| **Duração** | 1 hora / até dormir / até ordem contraditória |
| **Limite** | 1 alvo por vez; 3 alvos simultâneos (custo: 2 PM/alvo extra) |
| **Resistência** | Teste H Difícil; sucesso = imune 24h; falha = controlado |
| **Efeito Colateral** | Uso prolongado → usuário desenvolve **megalomania/paranoia** |
| **Quem Tem** | Senado (segredo), Arcanos sombrios, Eligos (Duque do Inferno) |

> **Proibição Absoluta**: Posse = pena de morte imediata (exceto autorizados).

## 🪞 Espelho Sangral

> *Artefato de proteção → instrumento de doutrinação do Senado/Imperador.*

| Função Original | Corrupção Atual |
|-----------------|-----------------|
| Proteção contra Trevas | **Espelha a alma**: mostra verdades/mentiras |
| Comunicação com Ordem | **Instrumento de doutrinação** (Senado/Imperador) |
| Visão passado/futuro | **Manipulação de memória/identidade** |

| Uso Atual | Detalhe |
|-----------|---------|
| **Interrogatório** | Suspeito olha no espelho → confessa tudo (teste H Difícil) |
| **Doutrinação** | Cidadão olha → personalidade reescrita (lealdade ao Império) |
| **Visão** | Imperador/Magistrado veem passado/futuro de alvo |
| **Localização** | Sala do Trono (Ypy) — acesso: Imperador + Magistrado Imperial |

> **Lenda**: Originalmente escudo contra Trevas; corrompido pelo Senado ao longo de séculos.

## ⚖️ Penalidades Legais (Imperiais)

| Crime | Pena |
|-------|------|
| **Posse de tecnologia proibida** | Morte imediata (execução pública) |
| **Fabricação** | Morte + confisco de bens da família |
| **Pesquisa/Estudo** | Prisão perpétua (campos de reabilitação Arcanos) |
| **Tráfico/Comércio** | Morte + confisco total |
| **Conhecimento Teórico** | "Reeducação" (lavagem cerebral; campos Arcanos) |
| **Uso de Orbe/Espelho** | Morte + confisco + família monitorada |

> **Exceção**: Arcanos Imperiais (em serviço), Senado (autorizados), Imperador (autoriza).
