## 🚀 Como Usar

### Carregar no Contexto
```bash
# No terminal do VPS
cat ~/r2d2-brain/worldbuilding/arcano/README.md
```

### No Chat (R2)
```
R2, carrega a bíblia de Arcano
```
Ou mencione arquivo específico:
```
R2, lê worldbuilding/arcano/lore/deuses.md
```

### No Jarvis (grupo RPG)
```
@jarvis_m4t4r0_bot lê workspace/contexto/arcano/deuses.md
```
