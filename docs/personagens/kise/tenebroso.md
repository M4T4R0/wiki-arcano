# Tenebroso

*Origem: [Kisé](../../imperio/reinos-vassalos/kise.md)*

Outro vencedor do torneio de [Vulcazar](../terra-selvagem/vulcazar.md) o mago assassino procurado em todo o mundo ganhou o comando do destacamento de magos de combate de Vulcazar.  Tenebroso é conhecido por suas magias devastadoras usando o poder do caos. Ele é muito parecido com Phry-Dhon, não se sabe exatamente se ele é uma cópia do Phry-Dhon ou Phry-Dhon uma cópia dele.
