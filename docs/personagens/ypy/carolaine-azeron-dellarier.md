# Carolaine Azeron Dellarier

*Origem: [Ypy](../../imperio/reinos-vassalos/ypy.md)*

Carolaine é a mãe de [Azeron](azeron-rasyl-azeron-dellarier.md), uma mulher elegante e bonita, mas com uma "frieza subjacente". Ela, juntamente com o pai de Azeron, negou o pedido de clonagem de um novo braço e olho para o filho, como forma de puni-lo por seu comportamento perigoso e desordenado.
