# Pai de Azeron

*Origem: [Ypy](../../imperio/reinos-vassalos/ypy.md)*

O pai de [Azeron](azeron-rasyl-azeron-dellarier.md) é um medimago que dirige uma clínica. Ele obrigou Azeron a estudar e se referiu ao filho como "a vergonha da família" se ele tentasse fugir para se tornar um mago aventureiro. Ele, juntamente com a mãe, negou a clonagem de um novo braço e olho para o filho.
