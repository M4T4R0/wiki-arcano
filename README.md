## 📖 Sobre o Cenário

**Arcano & Airy** é um cenário de fantasia sombria para **3D&T Alpha / Victory**, com:

- **22 raças jogáveis** (Aba, Abaré, Akitã, Kaapora, Piquira, Yawara, Abaité, Anaiti, Auçá, Abaquar, Icamiabas, Reptantes, Minotauros, Gnolls, Goblinoides, Meio-Elfos, Meio-Orcs, Licantropos, Meio-Gigantes, Kemonos, Icamiabas, + variantes)
- **Sistema de Mana/Trevas** integrado ao 3D&T Victory
- **Vantagens Regionais** — bônus grátis baseados na cidade/região de origem do personagem
- **Infestação** — ameaça cósmica que corrompe o oeste do continente
- **Política complexa** — Império Aba, Auçá, Abaité, Arcanos, facções internas
- **Lore profundo** — 300.000+ anos de história, deuses, cataclismas, cataclismas
